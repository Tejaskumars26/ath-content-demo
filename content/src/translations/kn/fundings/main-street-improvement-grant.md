## ಅರ್ಹತೆ

ನಿಮ್ಮ ವ್ಯವಹಾರವು ಗೊತ್ತುಪಡಿಸಿದ ಡೌನ್‌ಟೌನ್ ಜಿಲ್ಲೆಯಲ್ಲಿರಬೇಕು ಮತ್ತು **50 ಕ್ಕಿಂತ ಕಡಿಮೆ ಉದ್ಯೋಗಿಗಳನ್ನು ಹೊಂದಿರಬೇಕು**. ನೀವು ಸುಧಾರಿಸಲು ಬಯಸುವ ಕಟ್ಟಡವನ್ನು ನೀವು ಹೊಂದಿರಬೇಕು ಅಥವಾ ಗುತ್ತಿಗೆಗೆ ಪಡೆಯಬೇಕು.

* ವ್ಯವಹಾರವು ಕನಿಷ್ಠ ಒಂದು ವರ್ಷದಿಂದ ಕಾರ್ಯನಿರ್ವಹಿಸುತ್ತಿದೆ.
* ಸುಧಾರಣೆಗಳು ಬೀದಿಯಿಂದ ಗೋಚರಿಸುತ್ತವೆ.
* ನಿಮ್ಮ ಅರ್ಜಿಯನ್ನು ಅನುಮೋದಿಸುವ ಮೊದಲು ಕೆಲಸ ಪ್ರಾರಂಭವಾಗಿಲ್ಲ.

:::largeCallout{ showHeader="true" headerText="ಪ್ರಯೋಜನಗಳು" calloutType="conditional" amountIconText="Up to $20,000" filingTypeIconText="" frequencyIconText="" phoneIconText="" phoneIconLabel="" emailIconText="" }

ಹೊಸ ಚಿಹ್ನೆಗಳು, ಬೆಳಕು, ಕಿಟಕಿಗಳು, ಬಾಗಿಲುಗಳು ಮತ್ತು ಬಾಹ್ಯ ಚಿತ್ರಕಲೆಗಳನ್ನು ಒಳಗೊಳ್ಳಲು $20,000 ವರೆಗಿನ ಅನುದಾನಗಳು.

:::

## ಅರ್ಜಿ ಸಲ್ಲಿಸುವುದು ಹೇಗೆ

ಪ್ರಸ್ತುತ ಅಂಗಡಿಯ ಮುಂಭಾಗದ ಫೋಟೋಗಳನ್ನು ಮತ್ತು ಪರವಾನಗಿ ಪಡೆದ ಗುತ್ತಿಗೆದಾರರಿಂದ ಉಲ್ಲೇಖವನ್ನು ತಯಾರಿಸಿ. ನಂತರ ನಿಮ್ಮ ಅರ್ಜಿಯನ್ನು [ಆನ್‌ಲೈನ್ ಪೋರ್ಟಲ್](https://www.example.gov/apply/main-street) ಮೂಲಕ ಸಲ್ಲಿಸಿ.

:::largeCallout{ showHeader="true" calloutType="warning" }

ಅರ್ಜಿಗಳನ್ನು ಸ್ವೀಕರಿಸಿದ ಕ್ರಮದಲ್ಲಿ ಪರಿಶೀಲಿಸಲಾಗುತ್ತದೆ. ಪ್ರತಿ ವರ್ಷವೂ ಹಣಕಾಸು ಸೀಮಿತವಾಗಿರುತ್ತದೆ.

:::
